# Airtable type → Postgres (Supabase)

Source: Airtable field model and Postgres docs, Softr and AppMaster migration guides; read 2026-11-08.
Labels: **sourced**, **assumed**. `scripts/schema-from-airtable/map.ts` implements this table.

| Airtable type | Postgres pattern | Gotcha |
|---|---|---|
| singleLineText, multilineText, email, url, phoneNumber | `text` | Trim; empty string → NULL (sourced, AppMaster) |
| richText | `text` (markdown) | Images/@mentions inside don't carry over (sourced, Softr) |
| number / currency / percent | `numeric(p,s)` from precision; currency code in app.schema.json | Percent is stored 0.123 for 12.3% (sourced) |
| checkbox | `boolean not null default false` | Absent = false (sourced: empty omitted) |
| singleSelect | `text` + check constraint of options | Enums are hard to change; a check constraint is replaced in one migration (assumed) |
| multipleSelects | `text[]` | Junction table if they filter/report on it heavily (assumed) |
| date / dateTime | `date` / `timestamptz` | Field `timeZone` matters; check after import (sourced: options) |
| duration | `numeric` seconds | API gives seconds (sourced) |
| rating | `smallint check (between 1 and max)` | Cannot be 0 (sourced) |
| autoNumber | `bigint generated by default as identity`, old value imported | Users quote these numbers; preserve them (assumed) |
| createdTime / lastModifiedTime | `created_at` / `updated_at` (trigger) | Import Airtable's value; don't reset it (assumed) |
| createdBy / lastModifiedBy / singleCollaborator | `uuid` FK to `profiles` | Map by Airtable user id or email; unknown → NULL + warning (assumed) |
| multipleCollaborators | `jsonb` for now | Junction to profiles if it matters (assumed) |
| multipleRecordLinks | one side single → FK `<key>_id` on that side; many-to-many → junction `<table>_<key>_links(from_id, to_id, position)` | Airtable stores both sides (`inverseLinkFieldId`): make one relation, not two. `prefersSingleRecordLink` is a hint, not enforced: check data (sourced + assumed) |
| multipleLookupValues | SQL view `<table>_computed` | Values are arrays even for one link (sourced) |
| rollup / count | SQL view (subquery aggregate) | **Function not exposed**: infer from values; recompute, don't import as truth (sourced) |
| formula | same-row and immutable → `GENERATED ALWAYS AS (...) STORED`; NOW()/TODAY()/other rows → computed in the app | Generated columns allow only immutable functions on the current row, no subqueries (sourced: Postgres docs). Date → text casts are not immutable (sourced) |
| multipleAttachments | Supabase Storage object + `attachments` row (record_id, field, path, filename, mime, size) | URLs expire 2 h after the API returns them; Free plan 50 MB per file, 1 GB in total (sourced); bigger files are skipped by the copy and linked instead |
| barcode | `text` | Barcode type dropped (assumed) |
| button | no column; rebuild as an action on the record page | Keep the URL template (assumed) |
| aiText | `text` with the current value | Regenerate with an Edge Function if needed (assumed) |
| externalSyncSource | drop; record the source in kb/schema.md | Synced tables need a new sync job or a one-off copy (assumed) |
| unknown type | `jsonb` raw + note | New types appear without notice (sourced) |

## Formula functions with no direct SQL twin (assumed; check per base)
`DATETIME_FORMAT` (moment tokens → `to_char`), `WORKDAY`/`WORKDAY_DIFF` (holiday calendar), `DATETIME_DIFF` units,
`REGEX_*` (PCRE vs POSIX), `ARRAYJOIN`/`ARRAYUNIQUE` over lookups (cross-row → view), `RECORD_ID()`,
`CREATED_TIME()`/`LAST_MODIFIED_TIME()` (use the columns), `NOW()`/`TODAY()` (not immutable), `BLANK()`/`ERROR()`,
implicit text↔number coercion. Rule (sourced, AppMaster): a formula that only formats text goes to the UI; one
that decides money or status goes to SQL or TypeScript with a test.

## Data gotchas
Duplicate names that were "unique in practice"; empty vs NULL; time zones; record ids change, so any outside tool
that stores Airtable record ids breaks at cutover. Keep `airtable_id` on every table for the parallel run.
